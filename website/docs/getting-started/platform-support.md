# Platform Support

Hermes Agent runs on Linux, including x86_64 and aarch64 systems. Start with a [local source checkout](./installation.md). Native macOS and Windows runtimes are not supported.

Linux containers and Nix-based Linux installations have separate setup paths: [Docker](../user-guide/docker.md) and [Nix](./nix-setup.md). For aarch64 Android, see [Termux](./termux.md); Android can terminate background processes.
